Em dados/json/produtividade.json, chave de topo "metasSemanais": { atualizadoEm, fonte, semanas: [ { ini:"AAAA-MM-DD" (segunda), fim:"AAAA-MM-DD" (sexta), obras: [ { obra, tipo:"metas"|"pendencias"|"sem-meta", total (só pendências: nº previsto na semana), fonte (nome do PDF), lidoAte:"AAAA-MM-DD", lacunas:[texto], itens:[ { item, meta (número ou null), un, feito (número), estado:"ok"|"parcial"|"nao", obs } ] } ] } ] }.
- estado: ok = feito ≥ meta; parcial = algum feito; nao = nenhum relatório traz o item. Nunca invente quantidade: item sem evidência no relatório fica "nao" com obs. Itens de compra/entrega sem quantidade não entram. Registre em "lacunas" dias não lidos, relatórios cortados ("Ler mais") e obra sem relatório. Mantenha só as 4 últimas semanas. Atualize a semana em curso a cada execução (reescreva os itens com o executado acumulado) e feche a semana anterior na segunda.
